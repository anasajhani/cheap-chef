# Cheap Chef

Cheap Chef is a responsive, browser-based weekly meal planner for students and anyone cooking on a tight budget. Enter a budget, choose a store, set your available time and equipment, and generate a seven-day plan with a consolidated shopping list.

## Run locally

No build step or dependencies are required.

```bash
python3 -m http.server 8000 --directory dist
```

Then open `http://localhost:8000`.

## Features

- Budget-aware meal planning for 1–4 meals per day
- Walmart, Target, and Kroger price profiles
- Prep-time and kitchen-equipment matching
- Vegan, vegetarian, gluten-free, dairy-free, and nut-free filtering
- English, Spanish, and Arabic interfaces
- Consolidated grocery list with estimated store pricing
- Responsive layout and printable results

Prices are estimates for planning and can vary by location and date.
